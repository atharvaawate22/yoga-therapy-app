# pose-core

Platform-free pose logic for the Yoga Therapy clients: no DOM, no React, no
model runtime. The web app uses it now; the React Native app is meant to adopt
it later (plan milestone M8).

The Python backend (`backend/utils/`, `backend/yoga_pose_engine.py`) is the
source of truth: the classifier was trained on its features. Everything here is
a port that tests hold to the Python behaviour.

Today it holds the MoveNet keypoint contract (`src/keypoints.ts`). Its test
reads the keypoint names, skeleton edges and mirror pairs straight out of
`backend/utils/preprocessing.py`, so a change on either side fails CI. Feature
extraction, the body-presence gate, the classifier, the stability vote and the
correction rules arrive in M3, checked against golden fixtures generated by
the Python pipeline. See [`docs/web-app-plan.md`](../../docs/web-app-plan.md)
§C.
